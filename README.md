# Mountain Eats

Mountain Eats is a food delivery website that allows users to browse, order, and enjoy delicious meals from various restaurants. The platform provides an intuitive interface for customers to place orders and for admins to manage the menu items and orders.

---

## Features

- Browse a wide variety of food items with images and descriptions  
- Add food items to your order/cart  
- Place and track orders  
- Admin panel for managing food items (add, update, delete)  
- Image upload support for menu items  
- Responsive design for mobile and desktop  

---

## Tech Stack

- **Frontend:** React.js (or your chosen frontend framework)  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **File Upload:** Multer for handling image uploads  
- **Other:** RESTful API design  

---

## Installation

1. Clone the repository:  
   ```bash
   git clone https://github.com/your-username/mountain-eats.git
   cd mountain-eats
   
2. Install backend dependencies:
   cd backend
   npm install

3. Setup environment variables:
   MONGO_URI=your_mongodb_connection_string
   PORT=5000

 4. Run the backend server:
      npm start

5. Install frontend dependencies (if applicable):
   cd ../frontend
  npm install
  npm start


# Usage

Open your browser and navigate to http://localhost:3000 (or your frontend port)
Browse food items and place orders
Admin users can log in to manage menu items
